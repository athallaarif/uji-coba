Metodologi Pemodelan & Diskusi Ketidakpastian

Sesuai Kerangka Acuan Kerja PjBL SIG 2026 (GD4103 ITB)

1. Formulasi Model Dispersi Asap (Gaussian Plume & Angin-Jarak)

Sebaran konsentrasi partikulat halus ($PM_{2.5}$) dimodelkan dari sumber emisi titik api aktif (NASA FIRMS VIIRS 375m) menggunakan pendekatan dispersi adveksi-difusi sederhana yang dipengaruhi oleh vektor kecepatan angin ($u$), arah angin ($\theta$), dan intensitas daya radiasi api (Fire Radiative Power / FRP). Simulasi on-the-fly menghitung ulang geometri poligon plume secara real-time saat parameter diubah.

2. Validasi Spasial & Strategi Keterbatasan Data di Papua Barat Daya

Sebagaimana dicatat dalam KAK, ketersediaan stasiun pemantau kualitas udara permukaan (ISPU/AQMS) di wilayah Papua relatif terbatas dibandingkan Sumatera dan Kalimantan. Untuk mengatasi celah data tersebut, model divalidasi secara spasial menggunakan citra satelit Aerosol Optical Depth (AOD) Himawari-8/9 dan Sentinel-5P TROPOMI serta pencocokan catatan jarak pandang (visibility) dari Stasiun Meteorologi BMKG Bandara Domine Eduard Osok (DEO) Sorong.

3. Ketidakpastian Model

  • Tutupan Awan & Asap Tebal: Sensor optik satelit (VIIRS/AOD) dapat mengalami bias deteksi saat tutupan awan konvektif tinggi di pesisir Sorong.
  • Variasi Topografi Lokal: Efek angin darat-angin laut di pesisir Kota Sorong dan perbukitan di bagian utara memengaruhi pembelokan plume yang belum sepenuhnya tertangkap oleh model 2D homogen.
